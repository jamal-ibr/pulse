# Design

JARVIS-inspired HUD, kept clean and readable. Dark mission-control
surfaces with cyan instrumentation. Design serves the task; cyan marks
state, action, and selection only.

## Theme

Dark only. Deep navy black base with a faint top bloom and a 48px grid
at 3% opacity (in `globals.css` on `body`). No light mode.

## Color

All tokens live in `src/app/globals.css` under `@theme` (OKLCH):

| Token | Value | Use |
| --- | --- | --- |
| `bg` | `oklch(0.15 0.022 245)` (#040c14) | Page background |
| `panel` | `oklch(0.19 0.026 242)` | Cards, sidebar |
| `panel-hover` | `oklch(0.22 0.03 240)` | Hover surfaces |
| `edge` | `oklch(0.3 0.04 235)` | Borders |
| `ink` | `oklch(0.93 0.012 220)` | Body text |
| `ink-dim` | `oklch(0.7 0.028 225)` | Secondary text |
| `ink-faint` | `oklch(0.52 0.032 230)` | Tertiary text |
| `accent` | `oklch(0.83 0.13 210)` (#3fdef6) | Primary actions, active nav, good state |
| `warn` | `oklch(0.83 0.14 85)` | Warnings, mock mode |
| `danger` | `oklch(0.7 0.18 25)` | Avoidance flags, hard-rule banners |
| `info` | `oklch(0.75 0.11 250)` | Informational badges |

Rules: body text is always `ink` on `bg` or `panel`. Accent never
carries body copy. Danger banners outrank everything visually; the
avoidance flag is the loudest element on any screen.

## Typography

- Body: system sans stack, fixed rem scale
- HUD voice: `font-mono` (system mono stack) for the brand mark, card
  titles, stat values, nav group labels, and the data-mode chip, always
  uppercase with wide tracking at small sizes
- No display fonts, no fluid clamp sizes

## Components

Primitives in `src/components/ui.tsx`; shell in
`src/components/shell.tsx`.

- Card: `rounded-xl border border-edge bg-panel/80`
- Badge: tone tints via `bg-<tone>/10 text-<tone> border-<tone>/30`
- ProgressBar: tone fill with a 6px `currentColor` glow
- Buttons: solid accent (text `bg` colour) or ghost border; both have
  `focus-visible` outlines
- Status dot: `.hud-dot`, glows via `currentColor`, 2.4s opacity pulse
- Brand mark: `BrandMark` in shell.tsx, mono tracked, "OS" in glowing
  accent

## Motion

- Transitions 150 to 250ms, state changes only
- One ambient animation: the status dot pulse
- Everything is disabled under `prefers-reduced-motion`

## Iconography

PWA mark: concentric cyan rings with a glowing core on #040c14,
generated by `scripts/make-icons.mjs` (requires `sharp` on the module
path). Outputs in `public/` and `src/app/icon.svg` are committed.
